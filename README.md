# Zishen · IG English

Learner site for one student's IGCSE English as a Second Language course: class records, Extra Practice (practice by question type and full mock exams), a mistake log and a vocabulary log.

This repository holds only the page shell (HTML, CSS and JavaScript). It contains no course content. Class records, tasks, recordings, answers and the learner's work are delivered by a private course service after sign-in and are never stored here.
